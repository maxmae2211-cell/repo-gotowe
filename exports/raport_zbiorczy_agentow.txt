## 4. Kod do generowania histogramu czasów odpowiedzi (Python)

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv('kpi.jtl', sep=',', dtype={'elapsed': 'int64'}, usecols=['elapsed', 'success', 'label'])
df = df[df['success'] == 'true']
plt.figure(figsize=(10, 6))
sns.histplot(data=df, x='elapsed', bins=50, kde=False, color='steelblue', edgecolor='black')
plt.title('Histogram czasów odpowiedzi (ms)')
plt.xlabel('Czas odpowiedzi (ms)')
plt.ylabel('Ilość żądań')
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.savefig('histogram_czasow_odpowiedzi.png', dpi=300)
```

## 6. Instrukcje aktualizacji bibliotek Python (pracownik5)

- Aktualizacja do najnowszych wersji:

